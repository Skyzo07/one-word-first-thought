Entry for the make.fun competition **One Word, First Thought**
(`u-0xkianno-one-word-first-thought-106abaf8`).

The program writes exactly one word — **Defenestration** — to
`/output/entry.txt`: the act of throwing something out of a window.
Surprising, vivid, and funny on a second look — the first word that
came to mind, chosen, not generic.

Run it with `node main.ts` (Node 22+). It is deterministic: no network,
no clock, no randomness. A runtime guard refuses to write anything
that is not a single word of 1–24 characters.
